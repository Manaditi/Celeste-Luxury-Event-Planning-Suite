# Celeste-Luxury-Event-Planning-Suite
Editorial luxury GenAI event orchestration &amp; multi-user collaborative suite powered by Gemini 3.8 Flash. Features automated fiduciary budget calculations, minute-by-minute run-of-show timelines, vendor procurement checklists, sensory moodboards, and a live simulated team room with real-time presence indicators.
